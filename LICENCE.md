## 🧩 About

**Lineage 2 Helper** is a comprehensive overlay assistant for Lineage 2 on Windows featuring an in-game menu, HUD widgets, macro scripting, inventory tools, and clan utilities.

Inspired by classic MMO overlay toolkits and community helper packs.

## ✨ Features

### 🎮 Core Tools
- Overlay Menu — in-game panel for quick actions
- HUD Widgets — live health, mana, and target readouts
- Macro Scripts — bind repeatable combat and support routines
- Mouse Wheel Cast — cycle skills from the mouse wheel

### 🎨 UI & Cosmetics
- Custom HUD Themes — pick colors and layout presets
- Chat Filter — highlight keywords in the chat window
- Minimap Markers — tag key locations and NPCs
- FPS Counter — lightweight frame graph overlay

### 🏋️ Utility & Inventory
- Inventory Helper — sort, search, and tag items
- Clan Tools — roster notes and member list export
- Timer Overlay — track buffs, potions, and cooldowns
- Screenshot Key — one-press capture of the game view
